# Additions Bestiary

A Patchouli book for the Additions Bestiary modpack. This guide documents all the creatures, items, and mechanics added to your Minecraft experience.

## Setup

1. Install Patchouli mod
2. Place this modpack in your mods folder
3. Open Minecraft and look for "Additions Bestiary" in your Creative tabs or search for it

## Structure

- `patchouli_books/additions_bestiary/` - Main book directory
  - `book.json` - Book configuration
  - `en_us/` - English content
    - `categories/` - Book categories
    - `entries/` - Book entries (organized by category)
    - `templates/` - Custom templates (if needed)

## Adding Content

1. Create new entry files in `en_us/entries/[category]/[entry_name].json`
2. Create new categories in `en_us/categories/[category_name].json`
3. Reload the book in-game with Shift+Click on the pencil icon

For more information, see the [Patchouli Documentation](https://vazkii.net/mod/patchouli/).
